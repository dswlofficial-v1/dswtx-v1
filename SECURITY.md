# 🔐 Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in DSWTX, please report it privately.

Do not publicly disclose:

- Authentication credentials
- API keys
- Access tokens
- Personal information
- Exploitation details

Please provide enough information for the issue to be reproduced and investigated.

## Supported Versions

| Version | Supported |
|---|---|
| Latest | ✅ |
| Older releases | ⚠️ |

Security updates will be provided for supported versions when applicable.
